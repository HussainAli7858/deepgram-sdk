# Security Policy

## Reporting a vulnerability

Please report security issues privately to Hussain Ali (https://github.com/HussainAli7858).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/HussainAli7858/deepgram-sdk/issues

## Scope

This policy applies only to the generated TypeScript and Python SDKs in this
repository. Neither package is currently published to npm or PyPI.

This is an unofficial SDK for the REST public API, generated by
Hussain Ali. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
